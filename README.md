\# 🌲 Lumina Grove



\*\*A Cozy 3D Mobile Adventure Game Built with Unity 6\*\*



\## 🎮 About the Game



Lumina Grove is a cozy low-poly 3D exploration game set in a colorful fantasy garden with a charming Christmas atmosphere.



Explore the garden, complete quests, collect Christmas ornaments, and decorate the central Christmas tree to bring the grove to life.



\## ✨ Features



\- First-person 3D exploration

\- Mobile-friendly touch controls

\- Collectible items and quest system

\- Interactive Christmas tree decoration

\- Cozy low-poly garden environment

\- Particle effects and celebration sequence

\- Player nickname registration

\- Guest player authentication

\- Online leaderboard and score submission



\## 🛠️ Technical Highlights



\- Event-driven architecture

\- Modular and organized code structure

\- Object-oriented programming with C#

\- Separation of gameplay logic and UI responsibilities

\- Asynchronous online service integration

\- Player authentication and leaderboard integration

\- Mobile UI and touch input implementation



\## 💻 Technologies \& Tools



\- \*\*Game Engine:\*\* Unity 6

\- \*\*Programming Language:\*\* C#

\- \*\*Rendering Pipeline:\*\* Universal Render Pipeline (URP)

\- \*\*Backend Services:\*\* LootLocker

\- \*\*Platform:\*\* Android
